## 3. Missing items (NOT in the scoring doc)

1. **Due date — "Thursday wk23"** (brief p5 deliverables table). The doc never states when D7 is due. This should live in §1 or §2 so a scorer can immediately verify a draft hasn't already been submitted late.
2. **Peer weighting clarification for D7.** Brief p5 shows D7 as an individual submission at 50%, with peer weighting footnotes attached to D6. The doc does not state "D7 is NOT peer-weighted". A scorer reading the doc in isolation cannot rule out peer weighting.
3. **Late-penalty mechanism** beyond the "§17.4" pointer. A 1-line summary (e.g. "10% per working day, cap 40%", or whatever the Blackboard policy says) would let a scorer warn drafts near the deadline.
4. **Release 2.2 changelog narrative** (p10 explicit wording: *"Added mandatory project management appendix and individual report detail"*). The doc mentions 2.2 but doesn't quote the changelog row or explain that drafts before 6 Apr 2026 predate the current D7 sub-question structure.

6. **Cover page / appendices policy** — present but scattered; not stated explicitly as "items EXCLUDED from page count: cover, appendices, references, TOC". Worth one line in §1 hard-gates.
