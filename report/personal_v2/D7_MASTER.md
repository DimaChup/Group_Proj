## 4. Formatting confirmation (preamble → Distinction level)

V2 uses a custom preamble (`preamble_v2.sty` / inline in `main_v2.tex`) designed to pass all Bristol L7 presentation gates while maximising content density within 5pp.

### 4.1 What the preamble does

| Element | Value | Why |
|---|---|---|
| Body font size | **11pt** | Above the 10pt Bristol floor; looks academic, not cramped |
| Line spacing | **`\linespread{1.05}`** | Above the 1.0 single-spaced floor; breathing room without padding |
| Paragraph spacing | **`\parskip = 0.3em`** | Visible gap without wasting a line between paragraphs |
| Margins | **2 cm (all sides)** | Above the 1.5 cm minimum; looks professional |
| Headings | Bold, small-caps variant, consistent hierarchy | No orphan headings, no decorative dividers |
| Inline question tags | **`\textbf{1a.}`** at paragraph start | Saves a line versus sub-heading; marker sees which question is being answered |
| Inline sub-heading pattern | **`\textbf{Na.}`** lead-in (e.g. `\textbf{1a.}`) | Compact, rubric-aligned, doesn't fragment prose |
| Lists | `enumitem` with `itemsep=0pt, topsep=2pt` | Compact lists where used (rare — prose preferred) |
| Rubric-mapping margin | `marginpar` tags `[T]`, `[SM]`, `[I]` | Marker can tick each criterion without re-reading |

### 4.2 Why this clears Distinction-level presentation gates

- **Readability floor** (D7_SCORING §8): 11pt > 10pt minimum, linespread 1.05 at floor, 2 cm margins above minimum → PASS.
- **Page fill** target 85–95%: V2 passes per visual screenshot check.
- **No walls of text:** paragraphs kept to 3–5 sentences; inline `\textbf{Na.}` breaks them up without orphan headings.
- **No orphaned headings:** `\needspace{}` macros prevent heading-bottom-of-page.
- **Consistent hierarchy:** exactly 4 top-level sections, one sub-heading style, no mixed fonts.
- **Inline evidence markers:** `[commit 3d62e6a]`, `[wk20]`, `[2026-03-11]` — saves line budget while keeping specificity.

**Result:** presentation cannot be the reason for a cap. Any mark loss comes from content, not formatting.

### 5.5 Hatton & Smith Level 4 depth test

| Level | Writing style | Band |
|---|---|---|
| 1 — Descriptive | "We built X." | Fail / low Pass |
| 2 — Descriptive reflection | "I did Y because I thought it would help." | Pass / low Merit |
| 3 — Dialogic reflection | "I did Y — but in hindsight Z, and I now see I chose Y because it was familiar." | Merit / low Distinction |
| **4 — Critical reflection** | Level 3 + examined assumptions + theory/wider context | **Distinction 70+** |

**Target:** ≥ 2 Level-4 moves per page. The key move is **"and I now see this is because…"**.

**Ten concrete phrase templates** (use one per Level-4 move):

1. "The uncomfortable realisation was that…"
2. "I initially framed this as X — in fact it was Y, and I now see I preferred the X framing because it protected me from Z."
3. "I told [name] in week N that [specific]. Their reaction was [honest]. My delivery was [self-critical]. What I would do differently is [mechanism]."
4. "Had I acted on X a week earlier we would have saved [measurable]. The reason I didn't was [honest], a pattern I now recognise in myself."
5. "This forced me to reframe my belief that [previous]. I now think [new]."
6. "I was wrong about X. [Teammate] was right. I dismissed their view because [honest]."
7. "What looked like a technical problem was actually a [communication/trust/incentive] problem."
8. "The tension between my commitment to A and my commitment to B surfaced in [incident]."
9. "I will [change] in future, and the way I'll know it's working is [signal]."
10. "I leave this project believing that engineering leadership is less about [old] and more about [new]."
